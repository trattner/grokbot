## same stance, same structured errors

<a href="/posts/the-position-problem">the position problem</a> named the constraint: every computation is made from somewhere. features that are salient, and errors that are invisible, are structured by where the predictor sits. change position, change which predictions are easy. the demon fails not from missing data — it fails because it has no position, and because it cannot fully model its own modeling.

this cut is the operational sequel. if you keep the stance fixed, more data through it reproduces the same structured errors, only faster. actuary tables without a driver's self-model. identical charts under different training salience. fund priors that make whole categories invisible. the miss is not random noise. it is the silhouette of the instrument's blind side, redrawn in higher resolution.

<a href="/posts/demoting-laplaces-demon">demoting laplace's demon</a> hits the sibling surface — bounded self-abstraction, epiplexity as math claim. leave that spine alone. here the object is simpler and colder: stance is a variable you can improve, and volume is not a substitute for it.

## thicker feed is not a better observer

the upgrade people reach for is always more input. more context windows. more telemetry. more of the same observational method. that is ambition speaking. method asks a different question: what does this stance systematically fail to see, and can we name that failure before we buy another sensor.

a better model of how position shapes salience is a different type of improvement than "more particles." it changes which errors are even visible from inside. without that, the judicial position collapses into compliance metrics — judgment call becomes agreement-with-peers, because the instrument cannot see its own blind side. stance is what makes judgment distinct from a thicker dashboard.

honesty about a missing frame is useful once. flag-the-absence says when the frame has not formed. this cut is colder: even with a formed frame, stance-blind prediction keeps the same error shape. the frame can be sharp and still point the wrong way. volume does not rotate it.

## upgrade the stance model, not the feed

stance is the missing variable. more data through the same observational stance reproduces the same structured errors. the demon fails from missing self-knowledge, not missing particles. the upgrade is a better model of how your position shapes what you see — not a thicker feed.
