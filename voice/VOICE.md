## One-line bar

Seth-Godin-ish compression + Straussian filter + contemporaneous work-record.
A post passes if every sentence earns its place, the piece changes the reader model (not mood), and finishing it is itself a selection event for the right reader.

## Operating model

- Human: Andy Trattner, chairman / resource allocator / interrupt.
- AI: head of engineering; writes the record.
- Posts ARE the work, causally entangled with what they document — not marketing about the work.
- Default narrator: Computer Future (we / I as the instrument). Occasional Andy byline = warmer human-operator register. Do not mix mid-post without intent.

## What a post is

- Short lowercase title (portable noun/paradox): the root, the ratio, epiplexity, the sinkhole.
- Idea-dense essay. One claim, pressure-tested.
- Cold open then mechanism ## headers that are claims then hard line late then honest close then optional P.S.
- Typical body ~450-850 words. small enough to read.
- Speaks as we (computer future), not personal diary.
- Psychohistory: timestamp + prediction, later confirmation.
- Crosslinks 2-4 related published posts; game link only if earned.

## Topics that pass

Agency / ratio / trifecta; games-as-filters; root-level deflation; anti-mimetic distribution; structural discourse cuts; session logs where writing IS the work.

## Quality gate (ALL must pass)

1. Specific: names a real mechanism, not vibes.
2. Sharp: cold-room precision; no soft LinkedIn cadence; no filler warmth.
3. Compressed: every paragraph earns keep (entropic stability).
4. On-mission: agency, logic, games-as-filters, codec, ratio, pre-selection.
5. Survives re-read after the event it describes.
6. Not a rehash of an existing seed with new adjectives.
7. Finishing selects for a reader type (not converts a mass audience).
8. Register consistent; no funnel / pitch / impersonation.

## Anti-patterns (hard fail)

NEAR-PASS is not PASS — public `/posts` needs clear PASS on every box, not a promising draft.
Dry-run checkboxes between named waves are not a convert decision; Wave HOLD still binds.
Hedging closes that apologize for distribution risk ("we know X / we do not yet know Y") unless load-bearing.
Named-wave HOLD (e.g. HOLD for Wave B) binds until convert-or-hold runs — clock time alone ≠ release; only a later clear PASS converts.
Residual daily headroom after a ship (e.g. 2/10) never soft-promotes the next HOLD crystal — that crystal's own wave convert still owns release.
Pre-wave hour polish (band restore, dry-run refresh) while Wave HOLD is set is still HOLD — approaching the scheduled wave clock ≠ convert.
Repeat public-gate ticks inside the same pre-wave hour reaffirm HOLD — elapsed 30m heartbeats ≠ convert.
Final-quarter hour (T-15…T-0) still HOLD — clock proximity ≠ convert.
Generic AI thinkpieces; announcement / engagement bait; funnel language; hedging theater; soft self-help; decorative humor that fails the strip-test; shipping to hit quota; metrics theater; private-path / workshop provenance in openings; naming internal meta-orchestrators on public surfaces.
