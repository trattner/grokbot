**specialization is not capability**

Enterprise readers treat agent leaderboards as ranking portable capability. The variance table says otherwise: agent main effect <3% of total variance on every dataset/check type; agent-by-task interaction 7–23%. Leaderboards mostly rank specialization to the task cell, not a transferable agent factor.

Sharpeners from the paper (cite, don't pad):
1. Aggregate reliability collapses on the hardest task quartile (Eρ² on τ² action_checks: 0.752 → 0.000).
2. Training-cell reliability negatively correlates with held-out reliability (r = −0.90 on τ²) — the designs that look most reliable replicate worst.
3. Population diagnostics transfer (capability-gap ratio ~0.35–0.40); per-family agent rankings invert.
4. Trace-level MAST failure profiles are idiosyncratic; cell-level profiles generalize.

DDR packages the variance-component table into a one-page buyer reporting discipline. The CF cut: a ranked percent is not a ruling about what travels. Interaction is where the ranking lives.
